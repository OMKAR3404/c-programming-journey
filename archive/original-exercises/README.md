# Original exercise files

The two folders next to this repository contain the original assignment layout
that I started with:

- `C-practice_easyQuestions` has the easier and repeated practice questions.
- `C-practice` has the later challenge questions.

I am keeping those folders outside the main public learning path because they
contain duplicate ZIP files, vague filenames, blank templates, and a few
exercises that need more careful checking. The organized copies in `practice/`
and `challenge-practice/` are easier to follow. The assignment names are still
visible in the original folders when I need to look back at them.
